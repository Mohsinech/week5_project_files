# Team Directory (instructor reference for Session 5.1)

Open `index.html` in the browser. It loads users from a public API and handles four states:
loading, success, empty and error. Students start from an empty `script.js`.

Test the states in Chrome DevTools, Network tab:
- Throttling set to **Offline**, then click Reload: error message.
- Change the URL in `script.js` to `.../userz`: the 404 branch.
